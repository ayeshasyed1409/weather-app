
# SkyCast Weather App

A weather application built with React and Vite that lets users check the current temperature of any city.

## Features
- Search for a city
- View current temperature and weather conditions
- Simple, user-friendly interface
- Weather data powered by WeatherAPI.com

## Technologies Used
- React
- Vite
- JavaScript
- CSS
- WeatherAPI.com

## Getting Started
1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in your terminal.
